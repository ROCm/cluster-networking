# Cluster networking

This repository contains scripts for automating various checks and configuration settings for networking devices (NICs and switches) when setting up clustered GPU nodes for parallel compute operations. Scripts should be run on each individual node in a cluster according to the public [GPU cluster networking single node guide](https://instinct.docs.amd.com/projects/gpu-cluster-networking/en/latest/index.html).

## Using the scripts

To use the scripts, clone this repository in your compute environment. Ensure you make each script executable with `sudo chmod 755`.

## Troubleshooting

If you have problems with a script functioning, please submit an issue.
